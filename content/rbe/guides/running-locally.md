# Running RBE Locally

This guide covers building and running RBE locally for development against Kastrick frontends.

## Prerequisites

- Rust toolchain (`rustc` and `cargo`)
- Access to `https://github.com/Kastrick8/RBE`

## Build & Run

```bash
git clone https://github.com/Kastrick8/RBE.git
cd RBE
cargo run --release
```
